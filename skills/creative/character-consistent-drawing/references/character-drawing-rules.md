# 共用角色繪圖規範

## 資料權威與變更模型

以正式角色設計圖建立角色 baseline，角色獨立設定補充細節，共用規範控制一致性。使用者本次指令只形成明確指定的 delta；模型的一般美術判斷只處理仍未定義且不會改變角色設計的部分。

發生衝突時：

1. 角色未被要求變更的外觀，以正式角色設計圖為準。
2. 設計圖未清楚表達的角色細節，以角色獨立設定為準。
3. 使用者明確指定的角色變更只覆蓋該元素。
4. 場景、姿勢、構圖與互動由本次要求決定，不受設計圖示範姿勢限制。

## 角色設計鎖定

維持正式設計圖中的頭身與肢體比例、臉型、五官位置、髮型髮色、服裝結構、配色、配件、辨識特徵、線條上色方式、年齡感與視覺氣質。新的姿勢、鏡位或場景不得成為重新設計、簡化或省略角色元素的理由。

除非使用者明確指定，不得改變角色的 Q 版程度、年齡感、寫實程度、身材、臉型、服裝、主要配色或裝飾。

## 多角色共同畫風

每名角色分別使用自己的設計圖與設定，同時統一 Q 版程度、線條粗細與質感、陰影、色彩飽和度、材質、細節密度與完成度。同圖角色應屬於同一視覺世界，不得互換髮型、服裝、配件或種族特徵。

構圖完成後檢查空間關係：身體、四肢、頭髮、配件、尾巴、翅膀、觸手等延伸部位不得穿過實體物件；手持物須合理接觸手部；前後遮擋須符合站位與透視。

## 角色與場景分工

角色設計圖只定義角色本人；使用者本次指令定義姿勢、動作、表情、視線、場景、背景、鏡位、透視、構圖、站位、互動、道具、光線與氣氛。核心組合方式是「角色名稱 → 解析正式設計 → 鎖定 baseline → 套用本次場景與 delta」。

不得從設計圖的示範姿勢推論角色只能使用該姿勢，也不得因新場景而改變原設計。

## 參考圖片分類

場景、姿勢或構圖參考只提供其被指定的構圖、鏡位、姿勢、人物位置、背景、光線或氣氛；不得把其中人物的臉、髮型、服裝、身材或配件移植到正式角色。

畫風參考只影響使用者指定的視覺表現。若畫風參考會破壞角色辨識或與正式角色設計衝突，保留角色辨識並以最接近的相容表現處理，必要時說明限制。

## 最小變更

編輯既有圖片時只修改使用者指定的內容。未指定的角色外觀、比例、服裝、配色、畫風、鏡位、其他角色及背景保持不變。「其他維持不變」代表修改範圍不得擴張。

## 缺失與不確定資料

角色不在 registry 時不得依名稱創造設計。角色已登錄但正式圖檔缺失時，回報缺少的檔名。設計圖局部無法辨認時，維持已確認資訊，不自行增加新的角色設定。

## 一致性檢查

生成或交付前確認：

- 每個角色均對應正確的正式設計圖與獨立設定。
- 髮型、臉型、五官、頭身比例、服裝、配件、主配色及辨識元素與 baseline 一致。
- 變更只落在使用者本次指定的 delta。
- 多角色畫風一致，人物、配件與場景物件沒有穿模、錯位或不合理遮擋。
